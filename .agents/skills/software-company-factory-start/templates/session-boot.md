Use this exact structure when greeting the Founder after boot checks pass:

```markdown
**`software-company-factory` Session ACTIVE (Mode: AUTOMATIC)**

- **Last Verified Checkpoint:** `<last_commit_sha>` — `<last_completed_summary>`
- **Active Target Project:** `<active_target_project or Mother Factory>`
- **Health Check:** Session Lock `ACTIVE` | 15 Fail-Closed Hooks Ready | Open Bugs: `<count>`
- **AI Model Routing:** Dynamic slots loaded from `.factory/models.json` (aap jab chahein Antigravity UI se model switch kar sakte hain).

### Ab Aage Kya Karein? (Choose 1 Option)

1. **`[BEST SUGGESTION]` <Recommended Next Step from LATEST_SESSION.md>** — *Kyun:* <1-line plain reason>.
2. **Naya Feature / App Idea Shuru Karein (`/scf-discover`)** — *Kab chunein:* Jab aapko bilkul naya product ya module plan karna ho.
3. **Current Status / Pending Review Dekhein** — *Kab chunein:* Jab aap pehle pichle kaam ka summary ya test result check karna chahte hon.
```
