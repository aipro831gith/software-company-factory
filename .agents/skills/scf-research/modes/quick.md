# `scf-research` — Quick Mode (`modes/quick.md`)

**Slot:** `light_ops_slot` (or `worker_slot`)
**Use When:** `Lean` tier features, utility tools, UI enhancements, or single-question technical lookups.

## Quick Research Checklist (Max 5 Minutes)
1. **Clarify the 1–2 Unknowns:** Identify exactly what needs verification (e.g., "Which CSV export library works cleanly with TypeScript and Indian rupee formatting?").
2. **Verify Primary Sources:** Check official docs or existing project dependencies; tag every finding `[confirmed]`, `[likely]`, `[possible]`, or `[uncertain]`.
3. **Check 16 GB RAM & Windows Fit:** Reject tools that require heavy background Docker clusters or Linux-only binaries.
4. **Emit Concise Brief:** Write a focused `docs/product/RESEARCH-<slug>.md` with Triad Options (`[BEST SUGGESTION]`) and hand off immediately to `/scf-handbook` or `/scf-scope`.
