System Overview & Automatic Mode vs. Manual Slash Commands

What Is This Repository? (The "Mother Factory" Concept)

Software Company Factory is not a single business app. It is your reusable AI Software Engineering Operating System ("Mother Factory") designed for a non-coder Founder on Windows 11 (16 GB RAM, Intel Core Ultra 255H, cloud AI inference, max 3 parallel workers per wave, and max 4 lightweight always-on helper servers called MCPs).

Whenever you want to build a new product (like a Jewelry ERP), modernize an old Excel workflow, or safely upgrade an existing app, this factory runs a disciplined, verified software company inside your workspace.

1. Zero Unexplained Jargon Every time a technical word appears (e.g., Argon2id or Integer Paise), the system gives you a 1-line plain-English meaning and an exact Google-searchable keyword.
2. Triad Options ([BEST SUGGESTION]) You are never stuck with open-ended tech questions. The factory gives you 3 clear choices (Simple / Balanced / Enterprise) with pros, cons, and a [BEST SUGGESTION] tag.
3. "Grill Me" Edge-Case Protection Before locking any plan, the factory asks 3–5 real-world "what-if" questions (e.g., "What if a customer pays half cash and half UPI?") so surprises are caught before coding starts.

Automatic Mode vs. Manual Slash Commands

Mode How You Use It Best For
Automatic Mode Run /software-company-factory-start (or /scf-start), then talk in plain English. End-to-end features, new apps, or full client projects where you want the Orchestrator to drive every step.
Manual /scf-* Overrides Type a specific command like /scf-audit, /scf-change-impact, or /scf-sec-ops. Targeted tasks: auditing an existing repo, checking security before a demo, or debugging one stubborn bug.
Clean Shutdown Run /software-company-factory-end (or /scf-end). Saving your Git backup, updating STATUS.md & LATEST_SESSION.md, and unlocking the workspace.

Three Complete Client Roadmaps (With Real-World Examples)

Journey A Zero-to-One Idea — Example: Custom Jewelry ERP

Scenario: You want to build a brand-new Jewelry Store ERP from scratch (gold weight in milligrams, GST billing in integer paise, split Cash + UPI payments, BIS hallmark tracking, and staff role permissions).

Hardware note: If the jewelry counter later connects a serial weighing scale or barcode printer, the dormant scf-hardware-compliance plug-in activates automatically.

Journey B Reverse Engineer & Rebuild Legacy App / Excel — via scf-legacy-re

Scenario: A client runs their business on messy Excel macros, an outdated Tally/desktop tool, or an undocumented legacy codebase and wants a clean, modern web app without losing hidden calculation rules.

Journey C Upgrade or Modernize an Existing App Safely — scf-audit → scf-change-impact → scf-architect

Scenario: You already have a working app, and a client asks for a big mid-project change (e.g., adding multi-branch GST invoicing to a single-store app) without breaking existing customers.
